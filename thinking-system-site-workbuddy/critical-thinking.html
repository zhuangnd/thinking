思考与判断体系

批判性思维（审辨）

第一层 · 认知原则 · 贯穿全程的审辨纪律

批判性思维的本质不是"批评"，而是"审辨"——在接受、形成或改变一个判断之前，有意识地检查证据、逻辑、前提和不确定性，并据此形成尽可能可靠、可修正的结论。

核心论点

1. 批判的对象是四个，不是"别人"

对象核心问题
事实这是真的吗？证据可靠吗？
逻辑结论能从前提推出来吗？
前提有没有隐藏假设？前提成立吗？
结论证据支持到什么程度？有没有过度推论？

2. 批判性思维 ≠ 怀疑一切

  • 怀疑主义："我不相信。"
  • 审辨思维："相信到证据允许的程度。"
  • "目前证据不足，我暂时无法判断"——这本身就是高质量判断。

3. 核心结构：主张 → 证据 → 推理 → 结论

不断检查：主张是什么（事实还是观点）→ 证据是什么、可靠吗 → 证据真的支持主张吗 → 有没有逻辑跳跃、隐藏前提、反例/替代解释 → 结论应该有多大确定性。

4. 五项关键能力

  1. 区分事实、观点、推论（真正需要检查的往往是第三层）
  2. 检查证据质量：数据本身也需要被批判（来源、样本、偏差、截取、利益相关）
  3. 检查逻辑关系：相关 ≠ 因果（冰淇淋销量与溺水的共同原因案例）
  4. 主动寻找反证："什么证据能证明我是错的？"——不可证伪的观点已失去可检验性
  5. 识别认知偏差：确认偏误、幸存者偏差、锚定、权威偏误等；批判性思维不仅要批判外部信息，也要批判自己的思维（否则变成"确认偏误的高级形式"）

5. 成熟特征：允许改变观点

建立的不是"永远正确的观点"，而是根据证据不断修正观点的机制。新证据足够强却拒绝改变，说明系统出了问题。

6. 三个层次（逐层加深）

第一层
信息批判
"这是真的吗？"——真实性
第二层
逻辑批判
"即使是真的，能推出这个结论吗？"——有效性
第三层
自我批判
"我为什么相信这个结论？我的判断过程可靠吗？"——认知可靠性，最难

7. "critical"的本义澄清

critical ≠ criticize（批评），而是 evaluate / examine / discriminate / assess。
中文"批判"带对抗性和否定性预设；更准确的中文概念是"审辨"：审（考察核验）+ 辨（区分判断）。
它不是反权威，而是拒绝无条件接受权威；不是怀疑一切，而是拒绝未经检验的相信。

8. 比例性：校准相信程度

不是对/错二元判断，而是"证据支持到什么程度"：强证据+多重验证 → 高度可信；证据不足 → 暂不判断；充分反证 → 拒绝。本质是"校准自己的相信程度"的能力。

可复用产出 · 六问最小模型

日常判断的"六问清单"——可作为任何判断前的快速审辨检查。点击逐条点亮。

  • 是真的吗？
  • 证据可靠吗？
  • 为什么能推出这个结论？
  • 隐藏前提是什么？
  • 有没有其他解释或反例？
  • 什么证据会让我改变判断？

与其他主题的关系

  • vs 判断体系：前者是方法论（"我应该如何判断"），后者是规则体系（"面对不同问题依据什么规则判断"）；审辨思维可作为判断体系的元规则。
  • vs 结构化思维（最终结论）：
    • 结构化思维 = "构造理解"：把复杂对象组织成可理解、分析、处理的结构（拆解→分类→抽象→建模→关联→转换→整合）；接受"问题作为分析对象"，不等于接受问题的前提。
    • 批判性思维 = "控制认知质量"：贯穿全程的审辨纪律（审视→质疑→验证→比较→校准→修正）；从第一秒就存在，不是结构化完成后的步骤。
    • 结合点：结构化让你深入问题；审辨防止你在深入过程中不知不觉接受错误前提。
  • 衍生方向：第三个维度"概率/不确定性思维"——在不完全确定的情况下应该相信到什么程度、如何行动。
沉淀出的元规则（对个人判断体系的贡献）：
在分析开始之前，不预置结论；在分析过程中，不把问题中的前提自动当作事实；在分析结束之后，让结论由结构、证据和推理共同产生。
