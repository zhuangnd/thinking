讨论问题的基线

第三层 · 讨论机制

讨论基线（概念定义 → 标准约束 → 事实依据 → 逻辑遵循）不是讨论技巧，而是降低认知噪声的约束条件——它让讨论从"观点碰撞"变成"对象分析"；而衡量讨论的最终标准不是"说服对方"，而是"认知增量"。

推进脉络

  • 阶段 1 · 评价用户提出的三基线
    概念定义、标准约束、逻辑遵循 → 三者是一条完整链路
  • 阶段 2 · 补充第四条
    事实依据 → 形成"对象—标准—事实—逻辑"四基线
  • 阶段 3 · 宽容度问题
    日常 vs 严肃讨论 → "讨论精度模型"（基线不变，变的是精度要求）
  • 阶段 4 · 退出讨论问题
    日常讨论判不了对错，但能判断讨论是否还有价值 → "讨论终止判断"
  • 阶段 5 · 认知增量
    把讨论目标从"说服"转向"增加认知" → 完整六步框架；最终延伸出 DQF 页面设计

核心论点

1. 四大基线及其分工

基线本质防止的问题
① 概念定义确定讨论对象偷换概念、语义混乱
② 标准约束确定评价函数双方评价体系不同
③ 事实依据确定证据可信度前提本身为假
④ 逻辑遵循保证推理有效跳步、偷换、循环论证、相关当因果

逻辑只能保证"前提为真则结论成立"，不能保证前提本身真实——所以事实依据必须独立成层。

很多争论不是观点不同，而是讨论对象不同（"AI 取代程序员"需先定义 AI/取代/程序员）；或评价函数不同（NBA GOAT 之争：按 MVP 还是按巅峰高度，双方都可能正确）。

2. 讨论精度模型：基线不变，宽容度变

不同场景不是采用不同规则，而是不同的精度要求：

基线日常讨论严肃/学术讨论
概念定义可模糊，大致理解一致必须精确定义（操作性定义）
标准约束可默认社会共识必须显式标准 + 适用范围
事实依据接受经验、常识、新闻必须可验证、可复现
逻辑遵循允许跳步和直觉推理必须完整严谨

误差容忍光谱：闲聊 → 工作讨论 → 技术评审 → 科研 → 法律裁判 → 数学证明。

分配原则：讨论越重要、结论影响越大、可逆性越低，基线要求越高；交流启发型讨论可放宽但不能放弃基线。讨论成本是第二维度——不是所有问题都值得同等严谨。

3. 退出讨论也是理性结论

日常讨论往往无法判定结论对错，但可以判定讨论是否还有继续的价值——这是两个不同的问题。

四种"讨论无效"的情形：

  1. 概念没统一（讨论对象已不同）
  2. 评价标准不同且都自洽
  3. 价值观排序不同（逻辑无法证明哪种价值绝对正确）
  4. 事实依据不足（双方只在"我觉得"）

应停止的信号：价值观分歧且双方不接受调整、无新事实、不再回应论证只重复观点、进入情绪表达。

退出讨论 ≠ 认输 = 当前讨论已无认知增量。

4. 认知增量：讨论的目标重定义

两种讨论目标：

  • 说服（Persuasion）：以对方是否改变观点为准 → 易变成输赢和辩论技巧比拼
  • 认知增量（Cognitive Gain）：以是否获得新认知为准 → 包括新事实、更准确的概念定义、意识到另一种评价标准、发现自己推理漏洞、明确"目前无法下结论"、找到真正分歧点
讨论最大的价值，不一定是得到答案，而是缩小问题。
（"AI 好不好" → "我们真正分歧的是效率优先还是就业优先"）

高质量讨论的定义（即使谁也没改变观点）：讨论结束后，双方都能准确表述——

  1. 我的观点 ② 对方的观点 ③ 真正分歧在哪里 ④ 为什么目前无法统一

5. 完整六步框架

① 概念定义（同一对象吗）→ ② 标准约束（同一标准吗）→ ③ 事实依据（认可哪些事实）→ ④ 逻辑遵循（推理成立吗）→ ⑤ 认知增量（有新认知吗）→ ⑥ 是否值得继续（还有增加认知的可能吗）

第⑤步是整个流程的"收益评估"，第⑥步是"退出判断"。
