# 「思考与判断体系」展示网站 —— 设计建议方案（Qoder 版）

> 版本：设计提案 V1（待确认后实施）
> 依据素材：thinking_docs/ 目录下 8 份总结文档（1 份主体系总结 + 7 份子主题总结）
> 发布方式：静态单目录站点，纯前端，零框架零构建

---

## 一、设计理念：认知星座（Cognitive Constellation）

qwen 版走的是「信息设计 / 出版物」路线——白底细线、层级架构图、自上而下的阅读流。本方案提出一个截然不同的方向：

> **把整套体系呈现为一个可探索的"认知星座"——每个核心概念是一颗星星，概念之间的关系是连线，用户通过拖拽、缩放、点击来发现体系的全貌与细节。**

核心隐喻：
- **体系不是金字塔，而是星座**——层级是存在的，但更重要的是概念之间的横向关联（批判性思维贯穿所有层、对话横跨五层、元层反哺全局）；
- **探索而非阅读**——用户不是从上往下"读完"体系，而是在星图中"发现"体系；
- **动态而非静态**——节点有呼吸动画，连线有流动光效， hover 时关系浮现，点击时内容展开。

这个方向的优势：
1. **天然表达"循环性"**——体系最核心的特征是"不是建完就结束，而是持续迭代"，星座图的回环连线比层级图更能传达这一点；
2. **天然表达"贯穿"**——批判性思维作为贯穿色带在层级图中是一条竖线，在星座图中可以是一根穿过所有节点的光弦；
3. **探索感强**——适合"既能看全貌，又能深入子主题"的需求。

## 三、主页设计（核心：认知星座图）

### 3.1 首屏 Hero

全屏暗色背景，中央是缓慢旋转/呼吸的认知星座图。上方叠放：

- 站名「思考与判断体系」
- 副题：*"不是建立一套正确答案，而是建立一套能不断产生、检验和修正答案的系统"*
- 左下角：四个根问题入口按钮（我如何知道 / 我如何思考 / 我如何判断 / 我如何校准自身）

### 3.2 认知星座图（页面核心，Canvas 交互绘制）

**节点设计**：

每个核心概念是一个发光节点，大小按体系权重分级：

| 节点 | 层级归属 | 大小 | 色相 |
|---|---|---|---|
| 批判性思维 | 第一层（贯穿） | 大 | 琥珀金 `#F0A830` |
| 结构化思维 | 第二层 | 中 | 青蓝 `#38BDF8` |
| 基线 + 框架 | 第三层 | 中 | 翠绿 `#4ADE80` |
| 模型 | 第三层 | 中 | 翠绿偏青 `#2DD4BF` |
| 工程化思维 | 第四层 | 中 | 紫罗兰 `#A78BFA` |
| 个人判断体系 | 第五层 | 大 | 玫红 `#FB7185` |
| 对话实践 | 应用层 | 大 | 暖橙 `#FB923C` |
| 双轨引擎（元层） | 第零层 | 中 | 银白 `#E2E8F0` |

**连线设计**：

- **纵向主线**（层级递进）：实线，带缓慢流动的光点动画，表示"从上到下"的认知流程；
- **横向关联线**（跨层关系）：虚线，hover 时高亮——如"批判性思维→每一层"的贯穿关系、"对话→五层"的横跨关系；
- **回路虚线**：从"对话实践"回到"双轨引擎"的迭代回路，用脉冲光效表示"持续循环"。

**交互行为**：

1. **拖拽平移 + 滚轮缩放**：用户可自由平移和缩放星座图，从全貌到细节；
2. **hover 节点**：节点放大，显示该概念的一句话定位（浮层），相关连线高亮，其余淡化；
3. **click 节点**：弹出内容卡片（不跳页），展示该层的核心要点（2-3 个关键论点 + 关键词标签）；卡片底部有"深入阅读 →"按钮跳转对应子页；
4. **双击节点**：直接跳转对应子页；
5. **顶部视图切换**：提供「星座视图 / 层级视图」切换——层级视图退化为 qwen 版式的自上而下架构图（给不习惯自由探索的用户一个确定性入口）。

### 3.3 主页其余区块

1. **三个根问题 + 第四问**：星座图下方的四张半透明玻璃卡片，各列对应主题关键词，点击高亮星座图中对应节点群；
2. **主线流程条**：完整主线（面对现实→审辨审题→…→自我校准）做成横向时间线，每个节点对应星座图中的一个概念，hover 时星座图中对应节点脉冲高亮；
3. **文档索引**：8 份文档的简洁列表，作为 sitemap 和回查入口。

## 四、子页面设计

### 4.1 统一版式

七个子页共用一套版式骨架，但视觉基调与主页一致（暗色主题），保持沉浸感：

```text
┌ 顶栏：站名 + 八个节点导航（当前节点发光高亮）
├ 面包屑：星座全景 / 第N层·层名 / 篇名
├ Hero：篇名 + 一句话核心（大号引文，左侧发光竖线）
├ 推进脉络：纵向步骤线（节点圆点 + 连接线，带滚动渐显动画）
├ 核心论点：分节卡片（毛玻璃效果，悬浮于暗色背景上）
├ 可复用产出：清单式标签卡（可点击展开详情）
├ 星座定位：嵌入一枚"微缩星座图，高亮本主题节点及关联"
└ 页脚：上一篇/下一篇（按体系顺序）+ 返回全景
```

### 4.2 各子页专属交互模块

| 子页 | 定制模块 |
|---|---|
| 批判性思维 | "六问最小模型"做成可逐条点亮的检查清单（点击每条，对应星星在微缩星座图中闪烁）；"批判 vs 怀疑 vs 审辨"三栏对比 |
| 结构化×工程化 | 三类模型层级链纵向流程图（可拖拽排序验证理解）；四层抽象模型可点击分层穿透 |
| 讨论基线 | 四基线顺序流程（点击逐步构建）；精度/宽容度对比滑块（滑动调整讨论场景，实时显示对应的基线要求） |
| 对话 | 七步交流模型步骤条（点击每步展开技术细节）；三语境切换标签页（职场/亲密/公共），切换时背景色相微调 |
| 判断体系 | 四层构造堆叠图（从底部逐层构建）；证据排序可视化（可拖拽调整权重，显示领域区分注记） |
| 双轨引擎 | A/B 双轨对照布局（左右分栏，中间放总检验问题）——版式本身即内容 |
| 结构化笔记 | 还原"笔记模板"卡片样式，说明其作为跨会话记忆锚点的用法 |

## 五、视觉规范（暗色沉浸风）

### 5.1 风格基调

偏「深空 / 认知宇宙」路线：**暗色底、发光节点、毛玻璃面板、克制用色、信息密度适中**。不追求花哨，追求"在沉静中探索"的阅读体验。

与 qwen 版的「白底出版物」形成明确对比。

### 5.2 配色（CSS 变量化）

| 用途 | 色值 | 说明 |
|---|---|---|
| 深空底 | `#0F1117` | 主背景，近黑微蓝 |
| 面板底 | `rgba(255,255,255,0.04)` | 毛玻璃卡片底色 |
| 正文 | `#E2E8F0` | 浅灰白，暗底长文友好 |
| 次级文字 | `#94A3B8` | 标注、辅助说明 |
| 强调色 | `#F0A830`（琥珀金） | 关键结论、当前高亮、核心节点 |
| 辅助色 | `#38BDF8`（青蓝） | 链接、第二序列强调 |
| 分隔线 | `rgba(255,255,255,0.08)` | 细规则线 |
| 节点发光 | 各层对应色相 + `box-shadow` 光晕 | 节点呼吸感 |
| 连线 | `rgba(255,255,255,0.15)` 默认 / 高亮时取目标节点色相 | 关系可视化 |

### 5.3 字体与排版

- 标题：无衬线（系统 UI 字体栈），字重 600-700，字间距微扩；
- 正文：无衬线（系统字体栈），行高 1.8，正文栏宽约 68ch；
- 引文/一句话核心：字重 300，左侧琥珀金发光竖线；
- 代码/术语：等宽字体（JetBrains Mono 或系统回退）；
- 图表标注：小字号 + 低对比度，不抢注意力。

### 5.4 动效原则

- **克制而有生命感**：节点呼吸（opacity 微调，周期 3-4s）、连线光流（缓慢移动的光点）、hover 过渡（300ms ease）；
- **不干扰阅读**：内容面板内无动画，动画只在背景/星座图中；
- **性能优先**：Canvas 绘制星座图，requestAnimationFrame 驱动，节点数 < 20 无需优化；
- **减弱动效支持**：尊重 `prefers-reduced-motion`，降级为静态图。

### 5.5 响应式

以桌面阅读为主（与 qwen 版一致），仅保证 1100px 以下不破版：
- 星座图降为可双指缩放（touch 事件）；
- 栅格降为单列；
- 导航收为汉堡菜单。

## 六、技术方案

- **纯静态**：HTML5 + CSS3 + 原生 JavaScript（ES2022），零框架、零构建、零外部依赖；
- **星座图**：Canvas 2D 手绘（不用 D3，节点固定布局 + 轻微力导向扰动即可），交互用原生事件；
- **共享资源**：
  - `assets/css/site.css`（暗色主题变量 + 版式骨架 + 毛玻璃效果）
  - `assets/js/constellation.js`（星座图渲染 + 交互逻辑）
  - `assets/js/nav.js`（导航 + 面包屑 + 微缩图高亮）
- **子页微缩星座图**：复用 `constellation.js` 的渲染逻辑，传入 `highlight: [当前节点ID]` 参数即可；
- **目录结构**：

```text
thinking-system-site-qoder/
├── index.html
├── critical-thinking.html
├── structured-engineering.html
├── discussion-baseline.html
├── dialogue.html
├── judgment-system.html
├── metacognition.html
├── notes.html
└── assets/
    ├── css/site.css
    └── js/{constellation.js, nav.js}
```

## 七、与 qwen 版的对比

| 维度 | qwen 版 | qoder 版（本方案） |
|---|---|---|
| 视觉基调 | 白底、出版物感、信息设计 | 暗色底、深空感、沉浸探索 |
| 主页核心 | SVG 层级架构图（自上而下） | Canvas 认知星座图（自由拖拽缩放） |
| 导航隐喻 | 层级阶梯（逐层深入） | 星座探索（发现关系） |
| 交互重心 | 折叠/展开、hover 高亮 | 拖拽平移、缩放、节点弹出卡片 |
| 体系表达 | 层级优先（纵向） | 关系优先（纵横并重） |
| 循环性表达 | 虚线回路 | 脉冲光效回路 |
| 阅读体验 | "在读一本精心排版的书" | "在探索一幅活的认知地图" |
| 技术实现 | 手写 SVG + CSS 动画 | Canvas 2D + CSS 毛玻璃 |

两版共用相同的源文档、相同的页面结构、相同的子页内容——差异在视觉语言和交互范式。

## 八、实施分期

**V1（建议首批交付）**

1. `site.css` 暗色主题 + 版式骨架；
2. `constellation.js` 星座图渲染与交互（节点、连线、呼吸动画、hover/click）；
3. 主页：Hero + 星座图 + 根问题卡片 + 主线流程条 + 文档索引；
4. 7 个子页按统一暗色模板填充（含各自定制模块）；
5. 交付前校验：Canvas 渲染性能、暗色对比度 WCAG AA、`prefers-reduced-motion` 降级。

**V2（可选扩展）**

- 视图切换：星座视图 ↔ 层级视图（后者退化为 qwen 版式）；
- 搜索高亮：输入关键词，星座图中匹配节点脉冲放大；
- 体系演化时间轴（"关于本站"页）；
- 导出功能：将当前星座视图导出为 PNG 壁纸。

## 九、待确认的决策点

1. **视觉方向确认**：暗色沉浸风 vs 亮色信息设计风（qwen 版路线）——本方案选暗色，与 qwen 版形成互补；
2. **星座图默认状态**：默认「全局视图」（全部节点可见）还是「聚焦视图」（只高亮核心五层 + 元层，hover 时展开其余）——建议全局视图，节点数不多（8 个），一眼可见；
3. **子页内容颗粒度**：与 qwen 版建议一致——全量入页，这套文档本身就是提炼版；
4. **是否同步实施两版**：先做 qoder 版（本方案），qwen 版已存在可作为备选/互补；还是两版并行维护？

## 十、一句话总结

> qwen 版是「打开一本精心编排的认知手册」，qoder 版是「进入一片可以自由探索的认知星空」——同一套思想体系，两种互补的打开方式。
