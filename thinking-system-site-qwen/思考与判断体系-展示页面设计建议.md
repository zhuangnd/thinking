# 「思考与判断体系」展示网站——设计建议方案

> 版本：设计提案 V1（待确认后实施）
> 依据素材：thinking/ 目录下 8 份总结文档（1 份主体系总结 + 7 份子主题总结）
> 发布方式：静态多页站点，经 QW Pages 受控发布；纯展示型，无数据库

---

## 一、定位与目标

**不是把 8 份 markdown 搬上网，而是把这套体系做成一个"可探索的认知地图"。**

- **展示体系全貌**：主页以全景架构图呈现"第零层元层 + 五层体系 + 对话应用层"的完整结构，一眼看清各主题的位置与关系；
- **探索子主题精髓**：每个子主题一个独立页面，保留结构化提炼的层次（一句话核心 → 推进脉络 → 核心论点 → 可复用产出），支持由任一层级深入；
- **保持认知一致性**：页面语言与体系语言同构——"层级""链条""闭环""制衡"这些体系自身的概念，就是页面的组织概念。

三类用户场景都覆盖：**速览**（3 分钟看懂全貌）、**精读**（进入某主题读透）、**回查**（日后回来找一个概念/规则/工具）。

index.html  主页：完备版体系全景（架构图驱动）

## 三、主页设计（核心：全景架构图）

### 3.1 首屏 Hero

- 左侧：站名「思考与判断体系」+ 副题（取主线一句话的浓缩版：*"不是建立一套正确答案，而是建立一套能不断产生、检验和修正答案的系统"*）+ 三个根问题入口（我如何知道 / 我如何思考 / 我如何判断 / + 第四问：我如何校准思考者自身）；
- 右侧或下方：全景架构图。

### 3.2 全景架构图（页面核心，SVG 交互绘制）

自上而下的层级结构，对应完备版总图：

```text
第零层 元层：自反与制衡（双轨思考引擎）        ← 可折叠
   ▼
第一层 认知原则：批判性思维/审辨（横向贯穿条）
   ▼
第二层 问题处理：结构化思维（工具箱标签）
   ▼
第三层 讨论机制：基线+框架+模型（四基线小流程）
   ▼
第四层 执行机制：工程化思维（含人机协同标签）
   ▼
第五层 最终能力：个人判断体系（四层构造微缩）
   ▼
对话 = 应用与测试场（八步横向流程条）
   ↺ 循环回到第零层（虚线回路，标注"持续迭代"）
```

**交互行为**：

- 每个层块 = 可点击热区，hover 高亮 + 显示该层一句话定位，click 跳转对应子页；
- 批判性思维做成**贯穿全图的纵向色带**（视觉上体现"从第一秒就存在，不是某个步骤"）；
- 元层与对话层的回路用动画虚线表达"循环性"；
- 提供"分层折叠/展开"开关：折叠态只看六层骨架（速览），展开态显示每层的工具箱/构造细节（精读）。

### 3.3 主页其余区块

1. **三个根问题（+第四问）**：四张并列卡片，各列对应的主题关键词，点击同样进入子页；
2. **主线一句话**：完整版主线（面对现实→审辨审题→…→自我校准）做成横向步骤条/流程线，每一步 hover 显示对应主题；
3. **文档索引**：8 份文档的清单表格（篇名、主题、体系位置、一句话核心），作为"回查"入口和全站 sitemap。

## 四、子页面统一模板

七个子页共用一套版式骨架（一致的导航、面包屑、页脚），内容区按总结文档的天然结构分节：

```text
┌ 顶栏：站名 + 六层导航条（当前层高亮）
├ 面包屑：主页 / 第N层·层名 / 篇名
├ Hero：篇名 + 一句话核心（大字引文式排版）
├ 推进脉络：原文档的问答/阶段演进，做成纵向步骤线
├ 核心论点：分节卡片/表格（保留总结中的表格与模型图）
├ 可复用产出：清单式卡片（六问基线、五模板、四层构造等）
├ 与体系的关系：嵌入一张"微缩全景图，高亮本主题位置"
└ 页脚：上一篇/下一篇（按体系顺序）+ 返回全景
```

**"微缩全景图定位"是子页的关键设计**：每页右下角固定一枚小号架构图，高亮当前主题所在层——读者在任何子页都随时知道自己身在体系的何处，这是"探索感"的来源。

### 各子页专属交互模块（按内容特点定制）

| 子页 | 定制模块 |
|---|---|
| 批判性思维 | "六问最小模型"做成可逐条点亮的检查清单；"批判 vs 怀疑 vs 审辨"三栏对比 |
| 结构化×工程化 | 三类模型层级链纵向流程图；四层抽象模型可点击分层（以数据可视化案例为默认示例） |
| 讨论基线 | 四基线顺序流程 + 精度宽容度对比表；"退出讨论 ≠ 认输"结论卡 |
| 对话 | 七步交流模型步骤条；三语境切换标签页（职场/亲密/公共） |
| 判断体系 | 四层构造堆叠图；证据排序的可视化（逻辑>数据>经验=权威 + 领域区分注记） |
| 双轨引擎 | A/B 双轨对照布局（左右分栏，中间放总检验问题）——版式本身即内容 |
| 结构化笔记 | 还原"笔记模板"卡片样式，说明其作为跨会话记忆锚点的用法 |

## 五、视觉规范（亮色信息设计风）

### 5.1 风格基调

偏《经济学人》/ 信息设计（Information Design）路线：**白底、细线、高信息密度、克制用色、表格与标注优先于装饰**。不追求科技感，追求"经得起细读的出版物感"。

### 5.2 配色（CSS 变量化）

| 用途 | 色值 | 说明 |
|---|---|---|
| 纸底 | `#FDFCF9` | 微暖白，避免纯白刺眼 |
| 正文墨色 | `#1F2328` | 近黑，长文阅读友好 |
| 次级文字 | `#6B7280` | 标注、来源、辅助说明 |
| 强调色 | `#9E2B25`（深红） | 层级标题、当前高亮、关键结论——出版物式的克制红 |
| 辅助蓝 | `#2F5D8A` | 链接、第二序列强调 |
| 分隔线 | `#E5E1D8` | 细规则线，区块分隔的主力 |
| 层级色带 | 每层一个低饱和度色相 | 架构图与子页导航共用，形成"层=色"的全站记忆 |

> 备选：强调色改用深蓝 #2F5D8A 为主、深红作第二强调（若您偏好更冷静的基调）。

### 5.3 字体与排版

- 标题：衬线（Noto Serif SC / 宋体系）——出版物气质；
- 正文：无衬线（Noto Sans SC），行高 1.75，正文栏宽约 68ch；
- 表格：细线三线表风格（顶线/表头线/底线），斑马纹极淡或不用；
- 引言/一句话核心：大号衬线 + 左侧红色细竖线；
- 图表标注：小字号灰字 + 编号（图 1、图 2），学术出版物惯例。

### 5.4 响应式

以桌面阅读为主（与您既有内部检索页约定一致，不做移动端深度适配），仅保证 1100px 以下不破版（架构图横向滚动、栅格降为单列）。

## 六、技术方案

- **纯静态**：HTML5 + CSS3 + 原生 JavaScript（ES2022），零框架、零构建、零外部依赖（字体用系统回退栈，离线可开）；
- **共享资源**：`assets/css/site.css`（主题变量+版式骨架）、`assets/js/nav.js`（导航+面包屑+微缩图高亮）、`assets/js/diagram.js`（主页架构图交互）；
- **架构图**：手写 SVG（层级块+贯穿色带+回路虚线），交互用原生事件绑定，不用 D3（结构固定，不需要数据驱动）；
- **目录结构**：

```text
thinking-system-site/
├── index.html
├── critical-thinking.html
├── structured-engineering.html
├── discussion-baseline.html
├── dialogue.html
├── judgment-system.html
├── metacognition.html
├── notes.html
└── assets/
    ├── css/site.css
    └── js/{nav.js, diagram.js}
```

- **发布**：确认方案后经 QW Pages 以 `category: "static"` 发布整个目录；后续内容更新（如新增主题总结）只需加页面 + 在 `nav.js` 的页面配置数组里注册一行。

## 七、实施分期

**V1（建议首批交付）**

1. `site.css` + `nav.js` 骨架（导航、面包屑、子页模板）；
2. 主页：Hero + 全景架构图（含分层折叠）+ 根问题卡片 + 主线步骤条 + 文档索引；
3. 7 个子页按统一模板填充（含各自定制模块）；
4. 交付前校验：HTML 引用的 class/ID 与 CSS 逐项核对、JS 抽取后 `node --check`、无头浏览器截图走查主页架构图交互。

**V2（可选扩展，另行确认）**

- "关于本站"：体系演化时间轴（三基线→四基线→认知增量→完备版，体现"框架本身也在讨论中演化"）；
- 全文检索（原生 JS 前端索引，无后端）；
- 暗色主题切换（届时引入 `prefers-color-scheme` + 手动开关）。

## 八、待您确认的决策点

1. 强调色：**深红为主 + 深蓝辅助**（本方案默认，出版物感更强），还是深蓝为主 + 深红点缀（更冷静）？
2. 主页架构图默认状态：默认**展开**（信息全）还是默认**折叠**（首屏干净，主动展开）？——建议默认折叠六层骨架 + 展开提示。
3. 子页内容颗粒度：按总结文档**全量入页**（信息完整，页面较长，靠锚点导航），还是**精选入页 + "查看完整总结"提示**（页面更精炼）？——建议全量入页，这套文档本身就是提炼版。
